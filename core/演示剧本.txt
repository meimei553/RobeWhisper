RobeWhisper · 演示剧本（阶段 7 · 步骤 5）
========================================

目标：约 5–8 分钟走通「能看懂、能操作」的产品演示。
前置：已安装依赖；网站已开（见「回归与启动一页纸」）。

--------------------------------
0. 开场（30 秒）
--------------------------------
打开 http://127.0.0.1:8501
说明：这是自然语言驱动的机器人虚拟编程平台；默认不连真机、不强制校准。

--------------------------------
1. 自然语言执行（必做）
--------------------------------
[ ] 确认「Real-Sim-Real」勾选为关
[ ] 输入：把桌上的红色杯子拿起来
[ ] 看回复：动作 / 目标 / 轨迹帧数 / 实验编号
[ ] 再输入：回零
[ ] 再输入一次「把红色杯子拿起来」→ 可指出「经验复用：是」

--------------------------------
2. 实验与经验（必做）
--------------------------------
[ ] 滚动到「实验数据与经验库」
[ ] 指出中文表格：时间、成功、动作、引擎/模型、是否含 RSR
[ ] 说明文件在本机 experiments/ 与 experience/ 目录
[ ] 点「导出最近一次」演示包 → 下载 zip（说明：可复述证据，不含密钥；经验按臂模型分区）

--------------------------------
3. 模型与物理（选做，约 1 分钟）
--------------------------------
[ ] 「① 模型」确认当前为内置臂
[ ] 「② 物理参数」微调摩擦或阻尼并应用（可选）
[ ] 「③ 关节」看当前仿真状态变化（可选）

--------------------------------
3.5 接触试机（第13期选做，约 1 分钟）
--------------------------------
[ ] 能力区能看见「接触试机」能力说明
[ ] 点「切换到接触试机场景并抓一次」
[ ] 看诊断：「接触试机」一行（代理通过/未接触/不确定）
[ ] 确认文案没有说「已上岗抓住」
[ ] 点「恢复默认臂（无物体）」——日常演示仍用无物体臂

--------------------------------
3.6 多步试机（第14期选做，约 1 分钟）
--------------------------------
[ ] 能力区能看见「多步试机」说明
[ ] 点「多步样例」（或输入：先回零再抓红色杯子）
[ ] 看回复/诊断：多步试机共 2 步（home → grab）
[ ] 确认文案区分「多步编排」与「仿真细分 steps」
[ ] 说明：教学编排，不是工业连续作业

--------------------------------
3.7 场景位姿示意（补强包一，约 1 分钟）
--------------------------------
[ ] 能力区「接触试机」说明里能看见「不是相机」
[ ] 点「切换到接触试机场景并抓一次」（不必新按钮）
[ ] 看诊断：「场景位姿示意」一行（朝仿真方块，或写明尚未按物体坐标；都不是相机）
[ ] 看能力区「本次试机代理摘要」：位姿来源 / 接触 / 多步 / RSR
[ ] 若「经验复用：是」，位姿可能是「尚未按物体坐标」（沿用旧轨迹，不是相机）
[ ] 确认没有说「看见杯子」「已经抓住」「标定完成」
[ ] 点「恢复默认臂」——默认臂不编造物体坐标

--------------------------------
4. Real-Sim-Real（选做）
--------------------------------
[ ] 打开能力区：能看见「可选能力一览」与「开闭状态」
[ ] 勾选「执行成功后做一次 Real-Sim-Real 校准」
[ ] 再发一句指令（真发保持关）
[ ] 看「校准摘要」：对照来源应为人话「伪对照」（不是真机回流）
[ ] 可选：策略一行显示「默认（真优先，无则伪对照）」
[ ] 演示结束建议取消勾选，避免影响日常演示
说明：本机若要用假接收端验「真轨迹」标签，见清单 F 节
      `python -m plugins.robot.local_fake_receiver --with-trajectory`

--------------------------------
5. 真机（口头即可，无设备时跳过）
--------------------------------
说明：真机需按 plugins/robot/真机联调检查清单.txt
      打开 USE_REAL_ROBOT 并配置 HTTP 或 ROS；缺配置自动 Mock。
      第12期：对方可回传 trajectory；没有也能继续伪对照演示。

--------------------------------
收束话术
--------------------------------
「同一套 TaskSpec：虚拟试机 → 可选真机送单 → 可选虚实校准（有真轨迹优先，无则标明伪对照）；
这是自然语言试机平台，不是仿真毕业即可上岗抓取。」
