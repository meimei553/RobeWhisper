RobeWhisper · 自然语言能力说明（机械臂）
========================================

一、先澄清误会
--------------------------------
「只能抓红色杯子」不是产品最终目标，只是早期 Mock 演示词太少。
目标仍是：多种物体/动作的意图 → TaskSpec → 仿真试机 →（可选）真机。

二、两种解析后端
--------------------------------
1) mock（默认，不用密钥）
   - 本地关键词：抓/放/移/回零 + 颜色 + 物体
   - 已支持物体例：杯子、积木/方块、瓶子、盒子、工件、零件…
   - 颜色例：红/蓝/绿/黄/黑/白 → 如 red_block、blue_bottle

2) api（接真大模型，表达更自由）
   在项目根目录复制 .env.example 为 .env，填写：
     LLM_BACKEND=api
     LLM_API_BASE=https://api.openai.com/v1
     LLM_API_KEY=你的密钥
     LLM_MODEL_NAME=gpt-4o-mini
   保存后重启网站。缺任一项会自动回退 mock。

三、动作白名单（有意限制，保证安全可执行）
--------------------------------
grab（抓） / place（放） / move（移） / home（回零） / wait（等待）
完整表见：core/动作表_第14期.txt
说明：TaskSpec.steps 为多步编排（先A再B）；params.steps 为单次仿真细分，二者不同。

四、重要：target 是「任务标签」，不是视觉坐标
--------------------------------
仿真里不同 target 会记入实验/经验库，便于复用；
关节运动目前仍是示意动作。真要「看到红积木再抓」，需要后期视觉。
经验按 model_ref（臂模型）分区，默认不会跨臂乱复用。
实验 JSON 含 run_snapshot；网站可导出「一次演示包」zip 便于答辩拷贝。

五、可试例句（mock）
--------------------------------
- 把红色杯子拿起来
- 抓起红色积木
- 把蓝色瓶子放下
- 移动一下
- 回零
- 等待一下
- 先回零再抓红色杯子
- 回零然后抓起红色积木
（多步会写入 TaskSpec.steps；单句仍只有顶层 action）
