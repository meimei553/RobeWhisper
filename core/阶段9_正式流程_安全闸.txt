RobeWhisper · 第 9 期正式流程（安全闸与拒识纪律）
========================================
前置：总规划已微调为 1–10 成熟收口；11–15 后置但路径必须保持畅通。
本回合：只出方案，不写第 9 期业务代码（对齐旧「先方案后逐步击破」）。

一、本期目标
--------------------------------
在 TaskSpec 下游增加「安全闸」：关节目标限位裁剪或超限拒绝、执行超时保护；
危险/胡说样例可演示；诊断写清拦截原因。
相对第 8 期：从提示用户 → 执行前硬约束（不靠 Prompt 自觉）。


二、绝不堵死 11–15 的硬约束（本期设计红线）
--------------------------------
[x] 不改 TaskSpec / SimResult / ApiResult 主字段名
[x] 不删除、不改语义破坏 BaseRobot.execute_task / HTTP / ROS 发送 TaskSpec
[x] 安全闸做成可配置、可绕过记录：裁剪结果写入 params 或 metrics 旁路信息，
    不吞掉原始意图（便于第 11 期真机对照「意图 vs 裁剪后」）
[x] 不把「无真机轨迹」写成永久唯一 RSR 路径；伪对照逻辑可保留，第 12 期加真轨迹门槛
[x] 不写死「场景无物体」为唯一模型；不删 builtin 扩展点（第 13 期接触场景要能加 MJCF）
[x] 不把经验键改成无法扩展 model_ref（第 10 期标签、第 13 期场景要接得上）
[x] 不做 3D 主视口、不做视觉、不扩机械狗（第 15/更后）
[x] Pipeline 仍：NL → LLM → TaskSpec →（闸）→ engine.run_task → 可选 robot

口诀：第 9 期只加「执行前过滤器」，不加「新货币」、不拆「送单窗口」。


三、可行性
--------------------------------
| 项 | 评级 | 说明 |
|---|---|---|
| 关节限位裁剪 | 高 | 读模型 joint range 或配置默认 ±π；裁剪 joint_targets |
| 超限拒绝模式 | 高 | 配置 SAFETY_MODE=clip\|reject |
| 超时 | 高 | 已有引擎超时配置；run_task 包一层时钟即可 |
| 拒识样例 | 高 | mock 已有部分；补危险词 + 网站可点样例 |
| 诊断展示 | 高 | 接现有 capability_panel / 【诊断】 |
| 堵死 11–15 | 低风险若守红线 | 见第二节 |


四、不超过 5 个小步骤
--------------------------------
步骤1：安全闸契约与纯函数模块
  - 新增 core/safety_gate.py（或同级）：输入 TaskSpec → 输出
    {ok, mode, original_targets, applied_targets, violations, message}
  - 只读 constraints/params；不改主字段名；可单元测试、不依赖 Streamlit
  - 验证：超限样本被 clip 或 reject；合法样本原样通过

步骤2：接入 MuJoCo / Pipeline 执行前
  - run_task 或 Pipeline 在 engine 执行前调用安全闸
  - reject → ApiResult/SimResult 友好失败；clip → 带着裁剪后目标执行
  - 验证：故意超大 joint_targets 不再静默乱甩；烟雾不破坏阶段 4–8 主路径

步骤3：超时保护
  - 单次 run_task / step 循环墙钟超时 → 友好失败，不崩进程
  - 验证：可测短超时；正常指令仍成功

步骤4：拒识与危险样例 + 诊断文案
  - 危险词（如无视限位/全速撞）→ REJECTED
  - 网站诊断/能力区展示「安全闸拦截」样例说明
  - 验证：胡说、危险、超限三类可演示

步骤5：第 9 期验收 + 回归 + 「未堵死 11–15」检查表
  - smoke_phase9；复跑关键旧烟雾
  - 书面勾选第二节红线仍成立
  - 勘误入库
  - 状态：已完成（PHASE9_ACCEPTANCE_PASS）


五、步骤顺序
--------------------------------
1 纯函数闸 → 2 接入执行前 → 3 超时 → 4 样例与诊断 → 5 总验
